# Лучшие курсы на Stepik

Каталог качественных курсов на Stepik, отобранных на основе личного опыта обучения.

🌐 **Сайт:** https://stepik-best.org

## О проекте

Проект помогает находить полезные курсы на Stepik без необходимости просматривать
большое количество предложений самостоятельно.

В каталоге представлены курсы по различным направлениям разработки и тестирования.
Для каждого курса доступны описание, авторы, категории, стоимость и ссылка на страницу
курса на Stepik.

Проект не является официальным продуктом Stepik и не связан с платформой Stepik.

## Возможности

- просмотр каталога курсов;
- страницы с подробной информацией о курсах;
- поиск по названию, описанию и другим данным;
- фильтрация по категориям и стоимости;
- сортировка по названию и цене;
- поддержка бесплатных и платных курсов;
- отображение авторов курсов;
- форма для предложения курса;
- сохранение предложений пользователей;
- адаптивный интерфейс для мобильных устройств.
